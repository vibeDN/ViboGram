# Credits

Third-party work this project builds on or reuses, including assets used
without an explicit license grant. Verify licensing before any redistribution
beyond this repo's own personal/non-commercial use.

## Codebases

- **[Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS)** — the
  official Telegram iOS client this project is ultimately built on. Upstream
  ships no top-level `LICENSE` file.
- **[Swiftgram](https://github.com/Swiftgram/Telegram-iOS)** — the direct fork
  base for this project; most of the `Swiftgram/` module tree, the settings
  UI shell, and the CI/build-system scaffolding originate here.
- **[AyuGram4A](https://github.com/AyuGram/AyuGram4A)** — Android Telegram
  fork; ghost mode (skip read receipts / presence), streamer mode, and other
  privacy features were ported from its approach.
- **[Margelet](https://github.com/narezany/Margelet)** — Android Telegram
  fork; the invisible-Unicode text-effect marker concept (Dim/Rainbow/Big
  size) was ported from here, re-implemented independently and without their
  self-promotional watermark. License status not verified.
