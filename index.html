ViboGram

Гибридный форк Telegram для iOS — лучшее из Ayugram, Swiftgram и немного vibe✨

Собран из Swiftgram/Telegram-iOS с отобранным набором функций, портированных из двух Android-форков — AyuGram4A и Margelet. Личная сборка для ежедневного использования, а не коммерческий продукт.

Соберите сами

Шаги сборки не отличаются от upstream Swiftgram / Telegram-iOS — форк не трогает саму систему сборки. Нужен Xcode и Bazel, вызываемый через обёртку Make.py.

  1. Получите собственные api_id / api_hash на my.telegram.org — они не лежат в репозитории.
  2. Не называйте свою сборку «Telegram» и не используйте логотип Telegram.
  3. Прочитайте security guidelines Telegram, прежде чем работать с реальными аккаунтами.

Каждый прогон CI публикует неподписанный IPA с тегом v0.0.<номер сборки>. Подписывать его — LiveContainer, AltStore/SideStore, ldid — вам самим.

shell 
git clone --recursive -j8 \
  https://github.com/vibeDN/ViboGram.git

openssl rand -hex 8   # случайный идентификатор

python3 build-system/Make/Make.py \
  --cacheDir="$HOME/telegram-bazel-cache" \
  generateProject \
  --configurationPath=build-system/\
    template_minimal_development_configuration.json \
  --xcodeManagedCodesigning
